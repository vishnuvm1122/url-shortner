# Contributing to URL Shortener

Thanks for your interest in contributing! We welcome contributions of all kinds: bug reports, feature requests, documentation improvements, and code changes.

## How to Contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes in the branch and commit with clear messages.
4. Ensure tests (if any) pass and add new tests for new behavior.
5. Open a Pull Request against `main` describing the change and linking any related issues.

## Code Style

- Follow PEP 8 for Python code.
- Keep templates and static assets organized under their respective app directories.
- Use Bootstrap 5 classes for styling consistency.

## Development Setup

Follow the steps in the README to set up a virtual environment and install dependencies:

```bash
python3 -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install -r requirements.txt
python manage.py migrate
```

## Issues and Pull Requests

- When opening an issue, include a clear title and steps to reproduce.
- When opening a PR, include tests and update documentation as needed.
- The maintainer may ask for changes before merging; please be responsive.
