# Security Policy

Thank you for using this project. Security is important to us. If you discover a security vulnerability in this project, please report it as described below.

## Reporting a Vulnerability

Please report security issues privately by emailing the maintainer at:

vishnuedappal1122@gmail.com

When you send a report, include:

- A clear description of the issue
- Steps to reproduce the problem
- The impact of the issue (e.g., data exposure, remote code execution)
- Any PoC, exploit code, or screenshots that help demonstrate the issue

We will respond within 72 hours and work with you to address the issue.

## Supported Versions

This project supports the latest commit on the default branch (main). If your report affects a released version, please state the version tag in your message.

## Timeline

We will:
- Acknowledge receipt within 72 hours
- Provide regular updates until the issue is resolved
- Publicly disclose the issue after a fix is available (we will coordinate disclosure with the reporter)
